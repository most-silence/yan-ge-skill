## 成品：SKILL.md 是什么

不是语录合集，是一套「遇到新问题他会怎么想」的可执行认知模型：

- **25 个心智模型**：9 个（书籍线）+ 16 个（播客线），如总仓楼层制、
  时间是独立坐标、档位阶梯、割错比扛错便宜
- **看盘工作流**：先定性 → 日线方向 → 量能验证 → 分布读数 → 形态 → 小周期找点 → 时间坐标 → 位置感
- **表达 DNA**：碎句、口语、「兄弟姐妹」、无提纲体、无书面成语
- **诚实边界**：不荐股、不预测点位、不承诺收益；承认「赌」，不装预测

合规声明：本仓库及 SKILL 仅供研究与学习其思维方式，**不构成任何投资建议**。

## 事故与修正（为什么这仓库的日志值钱）

[PIPELINE_STATE.md](PIPELINE_STATE.md) 记录了全程翻车与翻案，几个代表：

- **3800/2800 方向翻转**：两个数字都被 ASR 听错，单条算术线索无法定案——
  拉真实区间后确认逻辑对、数字全错。此后立规：点位必须对账后才入库
- **「炒股不是一天的游戏」编造案**：改写主语 + 标错期次 + 虚构延展，
  靠脚本自验抓住。此后 v2 模板强制 `verify_quotes.py` <100% 重抄
- **三次检测工具自身出错**：归并比虚高、全线误报压平、对账表漏格——
  每次都是抽原始数据翻案。元教训：先验证工具再信结论
