## 每个文件的强制格式

```markdown
# 维度 0X · 名称

> Agent：0X ｜ 采集时间：YYYY-MM-DD ｜ 来源数：N（一手 a / 二手 b）

## 核心发现

（3–8 条，每条一句话）

## 详细记录

### 发现 1：xxx
- **内容**：……
- **来源**：<URL 或文件名>（一手 / 二手）
- **可信度**：高 / 中 / 低
- **原话**：「……」← 有原文就贴原文，没有就写「转述」

## 矛盾与疑点

（与其他维度的冲突、他前后不一致的地方——**保留矛盾，不要和稀泥**）

## 信息缺口

（本维没查到的、需要用户补素材的）
```

## 纪律

1. 每条信息标注**来源 + 可信度**
2. 区分「他说的」「别人说他的」「我推断的」
3. 发现矛盾**直接记录**
4. 不用知乎 / 公众号洗稿 / 百度百科 / 语录合集
5. 宁可写「信息不足」，不要编造填补
