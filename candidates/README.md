# candidates/ · 候选观点池

Phase 2 提炼时的**原始候选**，用于审计与回查。

## 放什么

- 从 `research/` 里扫出来的所有候选论点（通常 15–30 条）
- 每条标注：来源维度、原文摘录、初判（模型 / 启发式 / 丢弃）

## 为什么留

最终 `SKILL.md` 只放 3–7 个心智模型。但**被淘汰的也要能回查**——万一以后发现筛错了，这里还在。

## 格式

```markdown
| # | 候选论点 | 来源维度 | 原文摘录 | 三重验证结果 | 去向 |
|---|---|---|---|---|---|
| 1 | | 02 | | V1✅ V2✅ V3❌ | 降级为启发式 |
```
