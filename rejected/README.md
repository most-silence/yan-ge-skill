# rejected/ · 淘汰项与原因

被三重验证淘汰的候选，**连同淘汰原因一起留档**。

## 常见淘汰原因

| 原因 | 说明 |
|---|---|
| 排他性不足（V3 失败） | 所有理性投资者都会这么想，不是他的独特见解 |
| 无生成力（V2 失败） | 无法据此推断他对新问题的立场 |
| 来源不足（V1 失败） | 只出现过一次，且是转述 |
| 与本人后来观点矛盾 | 已被他推翻，但保留历史记录 |
| 疑似伪造语录 | 查不到原始出处 |

## 为什么不留删掉

淘汰不等于错。**保留「为什么不要」比保留「要什么」更能防止后期返工**——下次有人再提同样的候选，这里能直接回答。
