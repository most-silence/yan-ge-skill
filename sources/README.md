# sources/ · 一手素材投放区

把眼哥的**原始材料**丢进对应子目录。素材质量决定 Skill 上限。

> ⚠️ 转写规范见 [`../references/音频转写流程.md`](../references/音频转写流程.md)。
> **铁律：转写稿不许润色。** 口语里的卡顿、重复、自我修正，正是表达 DNA 的来源。

---

## 目录结构

```
sources/
├── 01-小宇宙转写/     ← 主力（近一年播客，逐期转写）
├── 02-抖音视频/       ← 少量，你直接丢进来
├── 03-其他素材/       ← 文章、访谈、实盘记录（如有）
└── 00-原始音频/       ← 可选，音频文件本体（体积大，建议不入库）
```

### 01-小宇宙转写/

| 项 | 要求 |
|---|---|
| 命名 | `YYYY-MM-DD_小宇宙_标题关键词.txt` |
| 格式 | 元信息头 + 带时间戳的正文（详见转写流程） |
| 进度 | 在 `PIPELINE_STATE.md` 记「已转写 N 期 / 共约 M 期」 |

### 02-抖音视频/

短视频通常自带字幕，优先导出官方字幕；没有字幕再 ASR。

| 项 | 要求 |
|---|---|
| 命名 | `YYYY-MM-DD_抖音_标题关键词.txt` |
| 格式 | 同播客，但可省略时间戳（视频短） |

### 03-其他素材/

- 公众号长文 / 雪球专栏（他本人写的，优先级最高）
- 媒体专访、连麦
- 实盘记录、持仓截图说明、复盘帖

---

## 优先级（决定采信权重）

| 级别 | 素材 | 说明 |
|---|---|---|
| **最高** | 他本人写的长文 | 完整论证，未经二次加工 |
| **最高** | 播客/直播原话 | 有语气、有即兴反应、有自我修正 |
| **高** | 实盘记录 | 真实行为 vs 声称，最硬的证据 |
| **中** | 第三方访谈 | 有提问压力，能看到边界 |
| **低** | 别人转述 | 需交叉验证 |

---

## 不收

- 知乎回答、公众号洗稿文、百度百科
- 「XX 语录合集」类二手汇编（失真率极高）
- 任何无法回溯到原始出处的截图
- **被 AI 润色过的转写稿**（出现「综上所述」「值得注意的是」→ 退回重转）
