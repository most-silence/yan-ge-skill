## 一、为什么必须校验

批读模板第一条铁律是「原话必须逐字摘录」。但**铁律本身不会自动执行**——
LLM 写「逐字摘录」时仍会顺手润色、补全、合并重复句。不校验的话，
整条审计链会在最源头断掉：

```
原话被润色 → 时间戳对不上 → 盲评时「这不是他说的」→ SKILL 可信度归零
```

> 玟火 `material-hygiene.md` §1：「转写稿不润色。表达 DNA 藏在口语里。润色一次，销毁一次。」
> 这句话约束的是**抽取者**，所以抽取者的产出必须可验证。

## 二、判定口径

| 判定 | 含义 |
|---|---|
| **全中** | 所有 >6 字的片段都能在原文找到 |
| **部分** | 部分找到 → 可能是正常省略（`……`），也可能是编造，需人看 |
| **全不中** | 一个都找不到 → 高度可疑，几乎肯定是编的或抄错期次 |
| **期次不存在** | 引用的 eid 在语料里没有 |

> 短于 6 字的片段丢弃。理由：「对吧」「是吧」在原文里到处都是，验不出真伪，
> 反而制造假通过。
