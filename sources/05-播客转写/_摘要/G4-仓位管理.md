### B07/B07-M74 · 不到技术位就不进场、不补：认定位置就等，挂到了才进

- **触发**：价格还没打到目标技术位（均线位、整数关口、前低、缺口）而盘中有反抽的时候；也包括强势票根本不回踩、等不到位置的时候。 -
- **动作**：不到就不进、不追高：认定在这个地方进就等这个地方进；有底仓的只拿底仓做 T，没有底仓的就等。要补仓也一样——不到技术位不补，先打「5 个 2」底仓。可以提前挂单让价格砸下来自己成交（挂在关键支撑位/整数关口下方一线）。反向的一条是：强势票不回踩到位时，买点可以从均线位往上提一点、先打底仓再慢慢加。 -
- **数字**：120-99 / 120-128 / 120-25 / 120-20 / 15-128 / 15-99 / 15-20 / 15-285 / 5-285；4000 / 4025 / 3880~3830 / 3816 / 3800–3825 / 3770 / 3737 / 3610 / 3347 / 2820~2850（创业板）；4082（缺口）；「挂 9 块 9 毛 3／等 90 挂 89 块 9」；「5 个 2」＝买 10 万先买 2 万；科技回调 30 个点以上；「只有三成可能不到就拉」。 
- **跨阶段**：R1(5次) / R2(17次) / R3(12次) / R4(3次) / R5(2次) / R6(12次) / R7(4次) / R8(3次) / U(5次) — 共 59 期 / 63 条候选 -

### B03/M06 · 技术破位或结构走坏就逐级降仓，不一次砍到底，也不清仓

- **触发**：关键技术位（120 分钟线、15 分钟线、区间下沿、整数关口）被跌破；主线大幅回调；出现背离；或自己判断环境畸形、风险大于机会。 -
- **动作**：按楼层刻度一级一级往下降，不一次砍到底，也不清仓；降仓的目的是低位接回、留出做 T 的仓位，不是躲利空。降的时候优先砍进攻板块，出现异动的方向先留着。 -
- **数字**：这波**只减到三楼以下**、4 月 7 号前只减到**五楼**（B03-193）；五层楼直接砍到**三楼**（B03-661）；技术全破 + 情绪冰点 → **三成以下**（B03-443）；破位后 **三楼**、科技不超 1.5（B03-622）；逃生梯度**满楼 → 五楼以下 → 三楼以下**（B03-796）；「降一点」＝八楼 → 七楼（B03-100）。 -
- **跨阶段**：R1(4) / R2(15) / R3(1) / R4(4) / R5(2) / R6(10) / R7(2) / R8(4) / U(15) — 共 54 期，57 条候选 -

### B03/M08 · 有浮盈就分档兑现，不一口气清，越涨越卖

- **触发**：手上已有浮盈（几档梯度：3~5 个点、5~10 个点、8~15 个点、十几二十个点、30~40 个点、翻倍）；或冲高、涨停、利好兑现、事件落地前后；或修复性上涨当天。 -

### B03/M01 · 不做单边：不满仓、不轻易空仓，永远留 10%~20% 现金弹药

- **触发**：任何行情下做总仓决策时；尤其下跌初期、变盘前、关键点位、以及有人问「要不要清仓」的时候。 -
- **动作**：不把仓位推到满，也不清到零；留出补仓/接回的现金，把「留一手」当成默认状态。留现金的理由是他自己说的三条：满仓＝赌单边、遇回撤补不回来、变盘点没子弹。 -
- **数字**：现金常留 **10%~15%**（B03-431）／**两成左右**（B03-542、B03-595）／「留够七楼才有子弹」（B03-572）；「任何行情至少留一两层」（B03-573）；「不要把仓位推得太高」（B03-287）。 -
- **跨阶段**：R1(8) / R2(5) / R3(2) / R4(1) / R6(10) / R7(2) / R8(1) / U(9) — 共 33 期，38 条候选 -
- **备注**：⚠️ 与 M28「深位可以打满」冲突；⚠️ 与 M05「看不懂就空仓」冲突（B03-089「不能空仓」vs B03-610「看不懂就空仓」）。B03-089 给的是反方向理由：空仓会转成空头思维、失去客观，这条与 M05 并列保留、不调和。

### B07/B07-M37 · 震荡/横盘/下降通道里用做 T 滚动代替加减仓

- **触发**：确认是震荡/横盘/下降通道的行情（没有增量、方向不明），或者手上是底仓不动、需要降成本的品种。 -
- **动作**：不做加减仓，改做日内 T / 滚动交易：底仓不动，用与底仓等量或不超过底仓的量来回滚；下降通道多做倒 T（先卖后买），上升通道多做正 T；卖掉的票当天哪怕涨上去也要买一些回来，不能让自己完全空掉。震荡行情「必须做 T，不做等于浪费行情」；不会做 T 的就拿着不动。日内 T 最多只做三分之一仓，不做半仓更不做全仓。 -
- **数字**：三分之一仓（日内 T 上限）；50 手底仓滚动 50 或 50+30 手；9 万本金每次 3 万；固定底仓 1300–1500 股（以便 200 股为单位滚）；18 个交易日内只涨 1.66% 靠每天抠一两个点做到 19 个点。 -
- **跨阶段**：R1(4次) / R2(14次) / R3(2次) / R4(1次) / R5(2次) / R6(5次) / R7(2次) / R8(5次) / U(4次) — 共 32 期 / 39 条候选 -
- **备注**：体量最大的两条之一，动作是「用 T 代替加减仓」这一件事，跨期次高度一致；数字差异（三分之一/50 手/3 万）是他按标的体量给的不同下限，写成区间保留。

### B03/M07 · 高位、压力位、整数关口只减不加：越涨越卖，绝不顶部加仓

- **触发**：指数/个股上到关键压力位或整数关口（本期语料里出现过的：4057、4125、4254、4000、4197、4050、4100/4125 区间、创业板 4000、上证 4254）；或已经是「位置太高、没经过回调」的票；或板块整体已在高位。 -
