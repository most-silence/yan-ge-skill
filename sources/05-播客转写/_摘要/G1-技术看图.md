## 怎么用这份摘要

### B10/B10-M01 · 只在预设技术位进场：不到位置不动手，到了就进

- **触发**：价格回调/下杀到事先算好的技术位（均线、前低、整数关、博弈区），或手里有票想补仓加仓、而价格还没到该位。 -
- **动作**：不到技术位不进场、不补仓、不提前抢（B10-111、B10-113、B10-115、B10-244、B10-393）；到了就按预案进，不因为怕它直接拉上去而提前，也不因为盘中情绪改主意（B10-546、B10-184）；进场量按档位（底仓/轻仓/重仓/打满）而不是一次性满仓；只用技术位作为补仓理由，“隔壁那只拉了”不算（B10-059）；计划定的接货区间被直接杀破就认该计划作废（B10-140）。 -
- **数字**：无统一阈值。示例：120-99、120-25、5-285、120-20、15-128=1837⚠️（B10-100）、3720-3690 / 3650（B10-285）、4025（B10-619）、3347（B10-315）、4050（B10-384）。 -
- **跨阶段**：U(10) / R1(11) / R2(15) / R3(7) / R4(8) / R5(3) / R6(9) / R7(2) / R8(1) — 共 61 期 / 66 条候选 -
- **备注**：本桶最大的父规则，只收“等位置 + 到位才动”这一个动作面；“到哪个位置算到位”归 M08/M09，“到位了买多少”归 M17/M30，“到位后是否确认”归 M14。特例性的宽严差异：B10-050（只有日内 T 才允许在急跌位加）、B10-130（长线仓在 120 分钟线附近再盘一下）。B10-125 的计划因价格没到而未成交，规则本身完整。与 M13“底部按区域、不按单点”在**精度口径**上收窄不一（见 §三 冲突 4）。 ---

### B10/B10-M03 · 到压力位或浮盈到档就减仓/止盈

- **触发**：价格走到上方压力位（前高、均线压力、整数关、套牢解套线），或者浮盈已经到预设档位。 -
- **动作**：减仓/止盈，**分批**（挂单挂在技术位，不追价）；压力位过不去就走，不耗在里面；明确不清仓（留基本仓）；没有前高、也没有压力位可用时，改用事先自设的百分比止盈，不临时问别人该不该卖；仓位高的、临近周末的、板块承载力有限的，减得更主动。 -
- **数字**：止盈档 **5 / 8 / 10 个点**（B10-486）；涨 **50%** 先出 50%、近 **100%** 再出一次（B10-493、B10-500）；深套反弹 **10~25 个点**减（B10-504）；利润 **10%** 时先卖 50~80 手（B10-234）；压力位 **4057 / 4125**（B10-051、B10-089）、**4197**（B10-424）、**3955**（B10-276）。 -
- **跨阶段**：U(6) / R1(3) / R2(12) / R3(6) / R4(4) / R6(10) / R7(7) / R8(3) — 共 48 期 / 51 条候选 -
- **备注**：本条把「按技术位止盈」与“没有技术位时按比例止盈”收成父子两层：父＝到档就减，子＝无压力位时改用百分比（B10-492、B10-493、B10-500）。B10-381（补的部分继续循环卖）是 B10-129 补仓动作的反向面，按动作归此。与 M04/M05“过压力位就转多”的边界见 §三 冲突 3。 ---

### B08/B08-M11 · 回踩到关键均线位才加仓、建仓，不到不动

- **触发**：手上有底仓或准备建仓，价格回踩到关键均线位、技术位、前低附近。 -
- **动作**：只有回踩到关键均线位才加仓、建仓、做日内梯；不到位置不动，哪怕当天涨得很好；回踩确认＋量能跟上才认这个位置；到了就分层加（1.8 楼 → 3 或 3.5 楼）；破位加速下跌时不补，等杀到 120 分钟 99 线才加。 -
- **数字**：档位：`15-99 / 15-128 / 15-225`、`120-25 / 120-99 / 120-128 / 120-225`；差 `30 点` 算「到也可以说没到」（B08-117）；量能前提 `2.8 万亿`（B08-170）；急跌两个位置：120-25 附近与前两日低点 4050/4055/4052（B08-215）。 -
- **跨阶段**：R1(7次) / R2(11次) / R3(2次) / R4(3次) / R5(1次) / R6(10次) / R7(1次) / R8(2次) / U(6次) — 共 40 期 / 43 条候选 -
- **备注**：本桶最大的一条（43 条 / 40 期）。子规则 M11-A 是同一触发下把动作升格为「必须上到高位」，父子两层不合并。 ---

### B10/B10-M24 · 区间/趋势里靠做 T 滚动降成本

- **触发**：判定为震荡/横盘/趋势不明，且手上已有底仓；或某些品种只适合做技术位 T+1。 -
- **动作**：高抛低吸做 T——仓位轻做正 T（先买后卖）、仓位重做倒 T（先卖后买）；到压力位减、到支撑位加，且“压力位敢减才有钱在支撑位加满”；卖了必须在支撑位接回，循环；T 的成败按**这一笔买入价**算，不按持仓成本算；空间不到 **1 个点** 就别做；只做技术位 T+1 的品种就只做 T+1；横盘越多越要做梯，震荡里不做就是浪费。 -
- **数字**：**1~2 个点**（B10-160）、**三到五个点**／七八个点甚至上十个点（B10-676）、**四五个点**（B10-016）、**6~7 个点**（B10-290）、**5~8 个点/10 个点** 过一个关口就卖（B10-575）、振幅区间 5~6 → 3~4（B10-655）。 -
- **跨阶段**：U(11) / R1(3) / R2(11) / R3(3) / R4(2) / R6(6) / R7(6) / R8(5) — 共 40 期 / 47 条候选 -
- **备注**：B10-478 明确加了准入门槛（“要有均线基本功的人才做”），作为本条的前置条件保留。B10-595（长期保留证券仓位、允许做 T 不许清仓）动作是持仓结构，但落点是“用 T 滚动”，归此。B10-620/627（冲高卖、回调接）与 M03 的减仓有交集，按“循环做 T”归此而非一次性止盈。 ---

### B10/B10-M04 · 突破与压力位必须用“量能/换手”验真，缩量即假

- **触发**：价格上攻或突破关键位（整数关、前期高点、均线压力）时，判断这是真突破还是假突破。 -
- **动作**：先看量能与换手，放量才算有效、才允许在回踩后加；缩量上破一律当假突破 → 不追、反而减仓（B10-258、B10-266、B10-600、B10-601）；换手不足时「压力反转支撑」不成立，仍按压力处理（B10-263、B10-494）；挑战次数已多、放量仍不过 → 判短期高点（B10-294、B10-438）；整数关下方反而希望它多磨、换足手（B10-173）；双闸门：过 4120 **且** 全天放量达标才算基本面改变（B10-269）。 -
- **数字**：**2.8 万亿**（B10-258）、**2 万亿 / 2.5 万亿**（B10-042）、缩量 **10%**、放量幅度从 **15% 缩到 10% 以下**（B10-257）、换手要盘够 **七根** 15 分钟 K（B10-179）、**4120 + 放量**（B10-269）、**2.2 万亿**（B10-702）。 -
- **跨阶段**：U(2) / R1(6) / R2(16) / R3(4) / R4(2) / R5(5) / R6(2) / R8(3) — 共 35 期 / 40 条候选 -
- **备注**：本条只收“上攻/突破的验真”。B10-337（上 4000 就减仓）与 B10-173（希望 4000 下方多磨）同组不冲突：都是“不让它没换手就过去”。B10-532（突破放量大、回落量极小 → 二类买点可追）是本条唯一的例外分支：量能差方向反，故保留为特例。B10-645（过 4057 后“触电式一到就直接下”是危险信号）、B10-482（先摸压力位再回踩做二次确认）均为形态维度，归此因落点仍是“突破成不成立”。 ---

### B08/B08-M10 · 到压力位先减一部分，站稳了再拿回来

- **触发**：手里的票或指数走到压力位（均线压力位、整数关口、前高、区间上沿）。 -
- **动作**：到压力位先减一部分，或按压力位分三单挂卖；不追、不冲；站稳或放量过上去再把仓位加回来；几条压力线汇聚到同一价位时尤其不追；无法盯盘就挂条件单（15-99 当卖点、15-128 当买点）；第一次杀到关键压力位大概率上不去，做 T 锁利润、保持仓位。 -
- **数字**：利润已达 `10%` 先卖 `50~80 手`（B08-137）；`5-20` 只要大于 `一个点` 就挂（B08-100）；压力汇聚示例 3590 / 3966 / 3888 / 3851 / 3991。 -
- **跨阶段**：R1(3次) / R2(12次) / R4(2次) / R6(8次) / R7(3次) / R8(1次) / U(5次) — 共 32 期 / 34 条候选 -
- **备注**：本桶第二大条；与 M11 不冲突——触发不同（到了压力位 vs 回到均线支撑位）。 ---

### B10/B10-M16 · 选方向：只做最强/资金流入/率先止跌的，不追已涨的

- **触发**：要在一个板块、几只票、或几个轮动方向之间挑。 -
- **动作**：挑“回调更深／率先止跌／走出二次探底（强势走法）／资金实际流入／技术位有支撑”的那一个（B10-292、B10-141、B10-472、B10-536）；不追当天已经涨掉的那个方向，改去看其他方向的回踩（B10-705）；主线已飞就切到主线里相对落后的环节（B10-642）；进入业绩/产品阶段只做龙头，不买便宜的没预期概念票（B10-473）；权重（银行）只当锚定标的，不当进攻方向（B10-666）；个股与板块共振时可在破位处加（B10-126）。 -
- **数字**：背离行业龙头平均跌幅 **5 个点**要谨慎、**>7 个点**有问题（B10-529）；个股涨幅超过板块 **2 倍**要谨慎（B10-654）；连拉 **两天**，第三天按分化处理（B10-474）。 -

### B10/B10-M19 · 破位就走：割错也走，不等回本

- **触发**：跌破关键位——支撑线、均线（120-25、120-99、120-128）、前低、结构位、15 分钟短線位。 -
- **动作**：走，**割错也要走**（B10-026、B10-182）；15 分钟破位必须看 120 分钟，两档隔得远就直接主动减仓，不等它跌到 120 分钟支撑（B10-033、B10-038、B10-559）；破位后不抄底、不按「博弈多头」处理、不补仓（B10-001、B10-562、B10-567、B10-568）；该走的时候走，别憋到破位最后才割（B10-485）；破位原因先定性：外因可修复，内因短期没救（B10-563）。 -

### B11/M03 · 破位即离场：不赌反抽、不留隔夜

- **触发**：破位已经确认（或盘中正在破），且下方没有就近承接——包括自己加仓点被跌破、前低附近再走一个破位下杀、以及非主线持仓的破位。

### B11/M01 · 破位成立口径：多周期确认 + 时间窗口 + 容差

- **触发**：要判定某个位置「算不算破位」「算不算站上」时，尤其是指数/个股刚跌破某条均线或某个前低的第一时间。

### B11/M02 · 破位先分级：弱势破位不等离场信号

- **触发**：已经出现破位，要判断这个破位的严重程度——是「弱势破位/洗盘」，还是「注定要跌」的恶性破位。
- **动作**：先分级再决定动作，不把一切破位都当离场信号。分级判据（都在用，不是每次都全用）：① 带不带量——缩量破位是弱势破位，放量下杀要谨慎；② 破位时间长短、是不是下午才破；③ 下杀有没有杀出恐慌盘、有没有大量内耗；④ 破位后有没有出新低、能不能粘住昨天低点；⑤ 原因是内因还是外因——外因一旦反转很快可修复，内因是年限级别的没救；⑥ 跌停处有没有承接、图形是否慢慢起稳（有承接可以「格局一下」不割）。判为弱势破位就承认偏弱但不降到位、不砍；判为恶性破位（放量下杀 + 关键位被杀破）才按 M03 处理。

- **动作**：① 到预定顶部区（例 4057 / 4125）就按良性调整、技术性回踩准备，不再按趋势加速追；② 区分筑顶与真上涨：同一价位瞬时放量或缩量冲上去再下来是标准筑顶，一级一级往上夯、每档都放量换手不是；③ 单顶结构只出现在牛熊转换，不是牛熊转换时单纯冲击失败的回踩不认顶（例 3497 不是顶）；④ 次日低开就确认双顶，按 120 分钟回调、第一目标 120-99（例 3888）；⑤ 炸板 + 水下直拉，判为出货、板块偏后期，转成以卖为主；⑥ 顶端放量下杀再拉高＝高位发套手法，宁愿错过也不做龙头首阴；⑦ 高位最怕单日急杀 150–200 点，要提前降仓，不等急杀发生；⑧ 高位横盘时间过长就先提醒风险，不等它跌下来再说；⑨ 科技顶不动 + 量价配合不好，就当它出问题了。

### B11/M22 · 做 T 与滚动套利

- **触发**：标的不给趋势方向（震荡/横盘/高位横盘），或某类票本就不指望主升，需要靠反复买卖挣利润、控亏损。
- **动作**：把 T 当成一套有纪律的动作，不是随手进出。① 仓位轻做正 T（先买后卖），仓位高（七楼八楼）做反 T（先卖后买），挂单看 15 分钟级别；② 做 T 前先写死「赌什么」，若没涨反而向下破位必须踢出去，不能顺势变成加仓；减仓同理，卖完又追回就成了加仓；③ 加速下跌段不做日内 T、不打反弹，该做的是减仓；④ 横盘整理、非主升浪的板块用做梯套利润（不做梯整段只涨 1~2 个点，做梯能做到 3~4 个点）；⑤ 大盘趋势股一定要做 T：拉起来先卖一半，不卖就没仓位接回落；强趋势票相反——不做 T 拿住，只有矿这类才做；⑥ 机构在下行通道里用倒踢维持仓位：先卖后接，既持股又减亏；⑦ 趋势没走出来时以日内 T 为主（加一点、减一点），不建立趋势仓；⑧ 震荡行情靠「坐梯」挣利润、控亏损；⑨ 高位横盘就做日内 T：拉上去卖、打下来接。
- **数字**：不做梯 1~2 个点 vs 做梯 3~4 个点（B11-163）；正 T / 反 T 由仓位高低决定（B11-057）；T+2 / T+3 替代 T+0（B11-041，见备注）。
- **跨阶段**：`R2(6) / R4(2) / R6(1) / R8(1) / U(1)` — 共 10 期 / 11 条候选
- **备注**：B11-041（不用 T+0，改用 T+2 / T+3，赌两三天后回到更低位置）是同一套滚动逻辑在下跌段的时间变体，触发与动作类别一致，合并但单列数字备查。 **边界**：本条只收「震荡/无趋势下的 T 与滚动」，趋势票的持有与止盈归 M23，仓位档位归 M21。

### B11/M20 · 加仓的前置条件

- **触发**：考虑在某个位置加仓（不是补破位仓，也不是摊成本）。
- **动作**：加仓要同时满足位置、形态、量能、板块四个方向里的多数。① 加仓三要素：形态给出加仓点 + 量能放大（比昨天放大 20% 左右）+ 放量的是进攻板块（半导体/科创/证券）；放量的是煤炭、房地产、银行这类防御板块就不加；② 回调/防守过程逐步加仓，上限可到计划仓的 80%~100%，超过 100% 才需要额外条件；③ 处在向下硬逻辑里、位置低的持仓，技术回踩就敢加；④ 急跌加仓只认两个位置：120-25 附近，与前两日低点（例 4050/4055/4052）；⑤ 技术位承接 + 前期低点双底成立才加，破位就不加；⑥ 要等它回到前低附近、或趋势明显走出来再加；⑦ 个股破位但板块更强、没击穿均线时，敢在破位处加（反向条件：板块也击穿则前提不成立）；⑧ 量能放大 + 看得到资金发力方向，才从 4 楼加到 5.5 楼。
- **数字**：量能放大 20% 左右（B11-085）；计划仓 80%~100%（B11-108）；急跌加仓点 120-25 与 4050/4055/4052（B11-136）；4 楼 → 5.5 楼（B11-265）。
- **跨阶段**：`R2(3) / R3(1) / R4(2) / R7(1) / U(1)` — 共 8 期 / 8 条候选
- **备注**：B11-045（个股破位但板块更强 → 敢在破位处加仓）与 M05 的「破位之后不加仓」方向相反，但它的触发是「板块强、个股弱」的共振判断，不是无条件的破位加仓，故不收进 M05，留在这里作为加仓条件的一个特例。 **边界**：本条只收「可以加仓的正面条件」，破位状态下能不能补归 M05/M06，加仓后怎么止损归 M04。

### B11/M06 · 补仓次数上限：常规两次、极值三次

- **触发**：持仓破位后决定补仓（或已经补过一次仍不见好），要决定还能补几次。

### B11/M12 · 双底（W 底）与二次探底的判定

### B11/M29 · 下行段不做高频细操作

- **触发**：确认当前是下行趋势（「信息不确定的下降续线」），不是横盘期；或大盘正在破位下跌而注意力还停在「现在能买什么」。
