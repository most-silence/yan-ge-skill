## 二、逐条展开

### B07-M01 · 看不清、没把握就不参与：空仓或极低仓位，把「零」当成正当选项

- **触发条件**：自己看不懂行情、对某个方向没把握、手上没有熟的票、图形看不明白、赢面明显偏小的时候；也包括「感觉/节奏不对」这种主观失配状态。
- **动作**：不下手。处置阶梯：①先不动、等方向明确；②仓位压到一成甚至 0.5 成；③直接空仓（「空一点就空一点」）；④连仓位档位意识都可以放弃——不为了维持某个楼层而必须买点什么。强调「不亏就是赚」「最好是 1，其次是 0，不要去选 -1」。
- **具体数字**：仓位梯度口径：一成 / 0.5 成 / 空仓；「三成可能不到就拉」不是本条数字（见 M74）。
- **跨阶段证据**：R1(2次) / R2(7次) / R5(1次) / R6(4次) / R7(1次) / R8(3次) / U(2次) — 共 18 期 / 20 条候选

### B07-M02 · 环境型不参与：下跌通道 / 熊市 / 加速下跌阶段以空仓为主

- **触发条件**：市场整体进入下跌通道、跌破结构、加速下跌、或某一阶段「特别难做」；也包括熊市这种长期环境。
- **动作**：不买板块、不挖票、不做日内 T、不打反弹；把仓位降到很低，能空就空（「最扛跌的状态是空仓」）。熊市打法的完整版是：大量时间空仓 → 等完全起稳 → 选一个方向埋伏 → 吃到肉就跑。

### B07-M04 · 不满仓也不空仓：满仓与空仓都是赌单边，保留底仓分批加减
