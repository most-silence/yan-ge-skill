## 一、五条铁律（违反即整条作废）

### 铁律 1 · 原话必须逐字，且必须用脚本自验

**写完一条规则的引文后，立刻用下面的命令自验。不通过就重抄，不许"看起来差不多"。**

```bash
cd E:\AIProjetct\Nothing\眼哥
tools\.venv\Scripts\python.exe tools\verify_quotes.py --batch NN
```

要求：**逐字率 100%**。有「部分」或「全不中」就打开 `_原话校验.md` 看是哪一条，回原文重抄。

**四条禁止**（都是 v1 实际犯过的）：

| 禁止 | v1 实例 |
|---|---|
| ❌ 不许改写词句 | 「炒股」写成「股票」 |
| ❌ 不许把分散在不同时间戳的句子拼成一句 | 把 [00:10:37] 和 [00:10:44] 的话压缩成一句 |
| ❌ 不许跨期次串话 | 把 3月27日 的话标到 5月7日 那期 |
| ❌ 不许补全他没说完的话 | 他只说半句就记半句 |

### 铁律 2 · 逐行抄，不要合并

**推荐格式（最不容易出错）**：

```markdown
**原话**：

> [00:10:28] 炒股不是一天的游戏
> [00:10:30] 大的外部环境没有发生
> [00:10:32] 根本性改变的时候就应该注意

—— `9irsiNse96VR` `[00:10:28]`~`[00:10:32]`
```

每行带自己的时间戳，**原样照抄原文的行结构**。这样最不可能串话。

### 铁律 3 · 数字必须原样，不做任何修正

ASR 会把点位听错（2800→3800、4000点→4000年）。批读阶段不裁决，原样记录 + 标 ⚠️。

### 铁律 4 · 不得补造他没说的话

如果他只说了半句（「这个位置……对吧」），就记半句。信息不足的进 `needs_review`，写清缺什么。

### 铁律 5 · 冲突不抹平

同一条规则出现两种相反说法，**两条都记，互相标注**。不许自己选一个，也不许调和。

## 二、四类去向

| 去向 | 判定 | 产出位置 |
|---|---|---|
| `verified` | 有触发条件 + 有动作 + 有原话 + 要素完整 | §A |
| `reference` | 有观点价值，但不是可执行方法（理念、感慨、经验谈） | §B |
| `needs_review` | 缺关键要素（缺动作、缺数字、指代不明） | §C |
| `rejected` | 纯闲聊、纯通知、纯情绪发泄、与其他候选重复 | §D（简记） |

> **不许为了凑数把 reference 硬包装成 verified。**
> 也不许把重要但信息不全的直接扔掉——进 needs_review，它是下一轮补读的工单。


## 六、背景知识（帮你识别信号）

- 眼哥：短线交易者，自称「老韭菜」，技术面为主，不用基本面估值
- 核心方法：5/20/99/128/225 五条均线、量能验证、多周期（15/60/120分钟）

  军线/军衔=均线、演哥=眼哥、家仓=加仓、为所=猥琐、草谷=炒股、
  提=踢、豆苗=标的、深藤系=深科技系、红弯=？
